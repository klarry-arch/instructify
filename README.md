# Instructify Kenya

Instructify Kenya is an education, training, consultancy, curriculum development, digital learning, and professional development organization.

## Deployment & Documentation

- **Live Deployment:** [https://vercel.com/klarry-archs-projects/instructify-oss2](https://vercel.com/klarry-archs-projects/instructify-oss2)

## Project Overview

- Modern UI/UX education platform built with HTML5, CSS3, and JavaScript.
- Accessible course catalog, resource center, institutional advisory, and training modules.
- Responsive design tailored for desktop, tablet, and mobile devices.
